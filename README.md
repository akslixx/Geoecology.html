# 🌿 Geoecology — Экология и окружающая среда

## 📖 О проекте
**Geoecology** — это образовательный интерактивный сайт, посвящённый геоэкологии и охране окружающей среды.

Проект помогает изучать экологические проблемы, природные процессы и способы сохранения нашей планеты.

## ✨ Возможности сайта
- 🌍 Информация о геоэкологии.
- 🌱 Красивый дизайн в природных цветах.
- 🖼️ Изображения на экологическую тематику.
- 📚 Несколько тематических разделов.
- 🔊 Озвучивание текста.
- ❓ Вопросы для проверки знаний.
- 🎨 Плавные анимации и переходы.
- 📱 Удобный интерфейс.

## 🎯 Цель проекта
Повысить интерес к геоэкологии, расширить знания об окружающей среде и привлечь внимание к защите природы.

## 🛠️ Использованные технологии
- HTML5
- CSS3
- JavaScript

## 🚀 Запуск проекта
1. Скачайте файлы проекта.
2. Откройте файл `index.html` в браузере.
3. Начните изучение геоэкологии!
